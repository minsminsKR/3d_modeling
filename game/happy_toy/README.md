# Happy Toy

`Happy Toy`는 낡은 여름 복도 분위기의 어두운 방을 탐색하는 1인칭 공포 게임 프로토타입입니다. Uncat과 Cyclopse가 순찰하다가 플레이어를 발견하면 추적하고, 플레이어는 1층 복도와 그 안에서 바로 이어지는 2층 계단을 돌며 열쇠 4개를 모아 마지막 방의 장난감 상자를 열어야 합니다.

## 실행

```powershell
cd E:\AI\3d_modeling\game\happy_toy
python web_server.py --host 127.0.0.1 --port 8010
```

브라우저에서 접속합니다.

```text
http://127.0.0.1:8010
```

맵을 직접 수정하려면 같은 서버에서 에디터를 엽니다.

```text
http://127.0.0.1:8010/editor.html
```

에디터의 `저장` 버튼은 현재 편집한 `MAP_CONFIG`를 `src/config/mapConfigOverride.js`에 기록합니다. 저장 후 게임 페이지를 새로고침하면 override 맵이 적용됩니다. `저장 맵 해제`를 누르면 override를 `null`로 돌려 기본 맵을 다시 씁니다.

디버그 HUD와 walkable/blocked/void overlay가 필요하면 URL에 `?debug=1`을 붙입니다.

```text
http://127.0.0.1:8010/?debug=1
```

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD | 이동 |
| Mouse | 시점 회전 |
| Shift | 빠르게 이동 |
| F | 후레쉬 켜기/끄기 |
| E | 문 열기/닫기, 열쇠 줍기, 캐비넷 숨기, 최종 장치 상호작용 |
| Esc | 일시정지 메뉴 열기/닫기 |

## 일시정지 메뉴

- `Esc`를 누르면 게임이 멈추고 중앙에 메뉴가 뜹니다.
- 옵션에는 마우스 감도 슬라이더가 있습니다.
- `다시하기`는 현재 런을 처음부터 다시 시작합니다.
- `종료`는 브라우저 탭을 닫는 대신 타이틀 화면으로 돌아갑니다.

## 현재 목표와 규칙

- 맵 곳곳의 방과 hwacat 이벤트 보상 위치에 배치된 열쇠 4개를 모두 찾습니다.
- 1층 복도에서 바로 보이는 계단을 통해 2층 인형방, 액자방, 기록 alcove를 탐색할 수 있습니다.
- 2층 액자방에서 `hwa_paint` 액자 앞으로 다가가면 액자가 벽에서 떨어진 뒤 hwacat 이벤트가 발동합니다. 카메라가 연한 붉은 얼룩 쪽으로 자연스럽게 돌아가고, hwacat이 누운 자세에서 일어난 뒤 10초 동안 춤추고 잠시 플레이어를 바라보다가 `Hwacat_angry` 몬스터로 변해 기존 몬스터 AI에 합류하며, 변신 위치에 네 번째 열쇠가 나타납니다.
- 깊은 복도나 2층 끝으로 갈수록 조명이 불안정해집니다.
- 기본 밝기는 후레쉬 없이 가까운 벽과 바닥 윤곽만 희미하게 보이도록 낮게 잡혀 있으며, 먼 복도와 방은 fog와 낮은 형광등 때문에 어둠 속으로 사라집니다.
- 복도에는 창살 낀 낡은 창, 늘어진 전선, 매미 허물, 종이 표식, 마네킹이 배치되어 있습니다.
- 계단은 복도 바닥에서 이어지는 짧은 랜딩, 보행용 램프, 시각용 계단 블록, 양쪽 벽, 벽부착 손잡이, 상부 계단실 측벽/천장과 벽등을 함께 써서 1층에서 2층까지 자연스럽게 이어집니다.
- 1층 계단 랜딩 서쪽의 빈 바닥은 `stair-west-alcove_1f` 설비 alcove로 확장되어 직접 진입할 수 있고, 서쪽/북쪽 벽, 선반, 벽등, 바닥 얼룩으로 막힌 void처럼 보이지 않게 채워져 있습니다.
- 2층 계단참은 정면 벽, 좌우 return wall, 남쪽 끝벽, 계단실 상부 천장 패널로 큰 빈 void가 보이지 않게 닫혀 있고, 복도 방향으로만 자연스럽게 꺾여 들어갑니다.
- 1층과 2층은 Y 높이와 두꺼운 바닥/천장 슬래브로 분리되어 있지만, 계단 입구는 복도에 열려 있고 상부 랜딩이 2층 복도 바닥과 직접 이어집니다.
- 벽, 바닥, 천장, 계단, 문, 캐비넷은 `../assets/textures`의 PNG 스킨을 사용하고, 열리는 문은 모두 방/공간과 연결된 미닫이문으로 동작합니다.
- 마지막 방의 장난감 상자에 열쇠 4개를 건네면 클리어됩니다.
- 몬스터와 충분히 멀어지면 추격이 풀리고 다시 배회합니다. 평상시 배회도 전역 waypoint를 사용해 복도, 방, 계단, 2층을 오가며 문이 열려 있지 않아도 가까이 가면 직접 열고 들어옵니다.
- 몬스터가 등을 보인 상태에서는 걸어서 지나가면 들키지 않고, 달리면 소리로 들켜 추격당합니다.
- 1층과 2층은 Y 높이로 분리되어 같은 X/Z 위치에 겹쳐도 다른 층이면 포획되지 않습니다.
- 층 이동은 계단 transition zone 또는 명시된 drop zone으로만 처리합니다. 같은 X/Z 아래에 1층 바닥이 있어도 검증된 landing point가 아니면 Y만 낮춰 이동하지 않습니다.
- `?debug=1`로 실행하면 화면 우상단 debug HUD에서 현재 floor, X/Z, tile type, 아래층 landing 가능 여부, 최근 drop target, 영역 카운트, 가까운 문의 connected room, stair waypoint, 몬스터별 floor/path target/stuck 상태를 확인할 수 있습니다.
- 런타임 사운드는 Web Audio 기반으로 활성화되어 있습니다. 형광등 험, 저주파 드론, 공간 리버브, 발소리/물소리, 피로 호흡, 위협도 기반 심박, 원거리 노크와 상호작용 효과음을 외부 음원 없이 합성합니다.
- 건전지는 손전등 잔량이 낮을 때만 소비되고, 에너지 드링크는 스태미너 회복과 짧은 속도 상승을 제공합니다. 폭죽은 실제 투척된 층의 바닥에서 폭발해 주변 몬스터를 폭발 지점으로 유인하며, 나침반은 남은 목표 방향을 표시합니다.
- 캐비넷에 숨을 수 있습니다. 추격 중 숨으면 대표 몬스터 한 마리가 캐비넷 앞에 서며, 20% 확률로 문을 열어 플레이어가 사망합니다. 몬스터가 캐비넷으로 천천히 다가오는 도중에도 E로 뛰쳐나올 수 있고, 이때 몬스터는 캐비넷 조사를 끊고 바로 다시 추격합니다. 나머지 80%의 "숨죽이고 기다리는 중" 상태에서 가만히 있으면 5초 뒤 몬스터가 다시 배회합니다.

## 파일 안내

전체 모듈 설명과 확장 가이드는 `PROJECT_MAP.md`를 봅니다.

## 검증

브라우저 자동 검증 스크립트는 초기화, HorrorEvent manager와 오브제, Web Audio 초기화, 벽/바닥/천장/계단/문/캐비넷/`hwa_paint` 액자 텍스처 적용, 미닫이문 패널 이동, 모든 열리는 문의 실제 방 연결, 다층 계단, locked/blocked door, 층간 추격/순찰과 stuck 방지, 층별 이동 규칙, 누적 시야 감지와 마지막 목격지 수색, 폭죽 소음 조사, 층간 포획 방지, 캐비넷 탈출, 일시정지, 아이템/열쇠/클리어 흐름을 확인합니다. 액자방 hwacat 이벤트는 별도 수동 플레이 테스트 또는 콘솔 기반 위치 이동으로 확인합니다.
