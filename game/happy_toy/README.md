# 그림자복도

폐교 1인칭 공포 게임입니다. 손전등 밖은 복도의 몫입니다. 흩어진 이름(혼) 4개를 모아 시작 홀의 제단함에 돌려놓으십시오.

맵은 지하 1, 본관 1층, 별관 1층, 2층 1입니다. 캐릭터 FBX, 소품 GLB, 벽/바닥 텍스처, 한국어 안내 음성(`voice/*.ogg`)은 모두 `../assets`에 들어 있어 clone만으로 플레이할 수 있습니다.

## 다른 PC에서 플레이

Python 3만 있으면 됩니다. 추가 패키지는 필요 없습니다.

```bash
git clone https://github.com/minsminsKR/3d_modeling.git
cd 3d_modeling/game/happy_toy
python3 web_server.py --host 0.0.0.0 --port 8010
```

브라우저에서 `http://127.0.0.1:8010` 을 엽니다. 에셋은 `/assets/...`로 `game/assets`에서 제공됩니다.

Windows:

```powershell
cd 3d_modeling\game\happy_toy
python web_server.py --host 127.0.0.1 --port 8010
```

## 한 판

- Uncat이 본관·별관 1층을 쫓습니다. 시작 홀(제단함)에서 동·서·남으로 나서면 교실 사이로 3.4m 복도가 이어집니다. 갈림길은 T자 교실 복도이고, 신발장은 교실 문 안에 있습니다. 한 길로 쫓기면 다른 갈림길이나 신발장으로 빠지십시오. 지하로 내려가면 계단 입구에서 기다리고, 지하에서는 Baby와 복도 실루엣이, 2층에서는 Hwacat과 실루엣이 담당합니다.
- 손전등을 비추면 실루엣이 잠시 멈춥니다. 신발장에 숨으십시오. 들키면 열립니다.
- 혼 4개: 지하 요람, 놀이방, 창고, 2층 액자 사건 이후.
- 별관에는 보건실·음악실·교무실·과학실이 따로 있습니다. 같은 교실을 두 번 지나치지 마십시오.
- 제단에서 E를 6초 동안 유지하면 탈출합니다. 멀어지거나 숨으면 봉인이 끊깁니다.

## 파일

- `src/` 게임 로직
- `../assets/` 캐릭터, 소품, 텍스처, `voice/*.ogg` 한국어 방송 (저장소에 포함)
- `vendor/three/` 로컬 Three.js. CDN 없이 실행됩니다.
