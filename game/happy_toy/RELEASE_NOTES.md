# 2026-09-10 품질 업데이트

## 최종 보완: 은신·등장 순서·밝기·건축 연결

- 운캣의 시간 기반 자동 추격 제거. 남쪽 복도 등장 이벤트가 끝난 뒤에만 추격 시작. 120초 경과만으로는 등장/추격하지 않는 것을 검증.
- 한 번의 은신을 무한히 재수색하던 문제 수정. 안전한 수색은 6.8초 뒤 종료하고 실제 경로를 따라 다른 순찰 지점으로 이동. 접근 실패도 10초 후 포기. 들어가는 모습을 직접 본 경우만 발각되며, 무작위로 벽장 위치를 알아내는 판정 제거.
- 수색이 끝난 뒤에도 계속 들리던 가짜 노크 제한. 숨은 플레이어를 향해 마네킹이 계속 경로를 추적하지 않도록 보완.
- 주변광, 반구광, 안개와 벽·바닥·천장 재질 보정. 손전등을 꺼도 네 구역의 구조가 식별되고, 켜면 세부를 더 잘 볼 수 있게 조정. 원작의 내부 조명 수치를 복제한 것은 아니며 실제 화면 가독성으로 검증.
- 문 위 인방, 문틀/문턱/패널 살, 벽 하부 걸레받이와 상부 마감 추가. 벽 생성 시 잘려 나가던 작은 구간을 보존하고 겹친 개구부를 병합.
- 막힌 외벽의 가짜 출입문 제거, 예절실 출입구의 기둥을 양옆으로 이동, 인형 교실과 예절실 사이 중복 문 제거.
- 소화기 보관대 모델과 한국어 안내 텍스처를 코드로 직접 제작해 실제 벽에 배치. 공중에 떠 있던 기록도 통행 가능한 벽면에 부착. 추가 마감은 인스턴싱과 공유 지오메트리로 처리.
- 47개 출입문의 닫힘/열림/양쪽 통행, 132개 방향 연결 검사 통과. 전체 이동, 추격, 6종 몬스터 모델/애니메이션, 수집/탈출/재시작, 손상 설정/에셋 실패 복구 검사 통과. 실행 오류·실패한 에셋 요청 0건.

- 검증 명령: `npm run verify:gameplay -- http://127.0.0.1:8014/`, `npm run verify:architecture -- http://127.0.0.1:8014/`.

## 추가 수정: 신발장 / Q키 멈춤

- Chrome 1280×720 재현에서 첫 신발장 진입 렌더링이 32,933ms 정지. 숨기/폭죽이 PointLight 수를 바꿔 장면 전체 조명 셰이더를 재컴파일하는 것이 원인.
- 신발장 내부 조명을 은은한 재질 발광으로 대체. 폭죽은 고정 조명 두 개를 빌려 사용하고 폭발/종료/재시작 때 반환. 여러 개를 동시에 던져도 조명을 추가하지 않음.
- 구역/소품/인형의 조명도 카메라 근처 기여도가 큰 12개의 고정 렌더 조명으로 처리. 원본 조명 위치·색·강도 애니메이션을 유지하면서 구역 등장/삭제에 따른 셰이더 재컴파일과 불필요한 조명 연산 방지. 레이어 31은 원본 조명용으로 예약.
- 반복 숨기/나오기, Q 투척/폭발/정리, 5개 동시 투척, 투척 중 리셋 검사 통과. 최신 실행에서 상호작용 렌더 호출 7.3~26.5ms, 추격·숨기·폭죽을 포함한 360회 게임 업데이트 p95 12.4ms, 최대 22.4ms. CPU 호출 시간이며 GPU 완료 시간/모든 PC의 프레임률을 보장하는 수치는 아님.
- `npm run verify:stalls -- http://127.0.0.1:8014/` 재현/성능 회귀 검사 추가. 이동·추격·모델·수집·탈출·재시작 회귀 검사 통과, 브라우저 오류 및 에셋 실패 0건.
- 기존에 열려 있던 게임 탭은 Ctrl+Shift+R로 새 코드를 로드해야 함.

기존 학교 공포 게임의 네 구역과 추격 동선을 유지하면서 모델, 탐색 안내, 연출, 설정, 재시작 안정성을 개선했습니다. 이 문서는 아래의 초기 품질 업데이트와 이후 보완 내용을 함께 기록합니다.

## 검증

Windows Chrome와 기존 로컬 Playwright로 검증합니다. Python 서버는 표준 라이브러리만 필요합니다.

```powershell
python web_server.py --host 127.0.0.1 --port 8014
node verification/check-syntax.mjs
node verification/verify-shadow-run.mjs http://127.0.0.1:8014/
node verification/verify-shadow-corridor.mjs http://127.0.0.1:8014/
node verification/verify-release.mjs http://127.0.0.1:8014/
node verification/verify-resilience.mjs http://127.0.0.1:8014/
```

- 모델 6종의 스킨 메시, 텍스처, 애니메이션, 모든 정점의 가중치 합 검사.
- 마네킹 2종의 GLB 메시와 텍스처 검사 및 시각 검수.
- 본관/별관/지하/2층 보행, 문 통과, 추격, 숨기, 포획, 수집, 봉인 탈출.
- Hwacat 변신/혼 보상, 비동기 생성 중 재시작, 타이틀 복귀, 문 상호작용 재연결.
- 저장 설정, 손상된 기록, 층별 등장 조건, 포커스 이탈, FBX/텍스처 누락 상황.
- `verification/release-qa/`에 모델/구역/수첩 PNG와 `release-report.json` 저장.

이번 실행 결과: 46개 게임 모듈과 Python 서버 구문 검사, `verify-shadow-run`, `verify-shadow-corridor`, `verify-release`, `verify-resilience`, 기존 `verify-restart-interaction` 통과. 최종 통합 검증에서 브라우저 실행 오류 0건, 실패한 에셋 요청 0건. 모델 6종 모두 실제 메시/텍스처/애니메이션 확인, 마네킹 2종 GLB 확인.

원본 FBX의 4개 초과 스킨 가중치 메시지는 로더의 변환 경고입니다. 실제 적용된 가중치는 정규화 후 검사합니다. 음성은 기존 합성 음성을 유지합니다. 자동 검증 통과는 모든 하드웨어/브라우저에서 오류가 없음을 보장하는 의미는 아닙니다.
