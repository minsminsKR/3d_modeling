# Wave System

## 목표

적 웨이브는 플레이 시간이 길어질수록 수량, 체력, 특수 패턴이 증가해야 한다. 단순히 체력만 올리는 방식이 아니라 빠른 적, 탱커, 폭발형, 원거리형, 보스를 섞어 게이트 선택과 화력 성장을 계속 시험한다.

## 관리 위치

`enemies/enemy_manager.py`가 적 풀링, 웨이브 생성, 적 이동, 적 사격을 담당한다. `GameManager`는 처치 결과를 받아 보상과 HUD를 갱신한다.

## 적 타입

| 타입 | 등장 기준 | 특징 |
| --- | --- | --- |
| `basic` | 시작부터 | 표준 체력과 속도 |
| `fast` | 3웨이브 이후 | 낮은 체력, 빠른 접근 |
| `tank` | 5웨이브 이후 | 높은 체력, 느린 이동 |
| `exploder` | 7웨이브 이후 | 중간 체력, 압박용 속도 |
| `shooter` | 9웨이브 이후 | 플레이어 방향으로 탄 발사 |
| `boss` | 8웨이브마다 | 거대 체력, 반복 탄막, 대량 보상 |

## 웨이브 형태

`spawn_wave()`는 다음 형태 중 하나를 고른다.

- `line`: 좌우로 넓게 선형 배치
- `double_line`: 두 줄 배치로 총알 밀도를 요구
- `pinch`: 양옆과 중앙을 압박
- `cluster`: 랜덤 군집 배치

웨이브 수가 증가할수록 기본 수량이 늘고, `wave_multiplier`로 체력과 일부 속도가 증가한다.

## 스폰 거리

적은 플레이어보다 약 66m 앞에 생성된다. `next_spawn_z`와 `spawn_interval`로 관리하며, 시간이 지날수록 스폰 간격이 약간 줄어든다. 너무 많은 적이 뒤에 남지 않도록 플레이어 뒤쪽으로 충분히 멀어진 적은 제거된다.

## 보스

보스는 8웨이브마다 등장한다.

- 큰 scale과 높은 체력
- `shooter`보다 빠른 탄막 주기
- 높은 `points`로 경험치, 코인, 젬 보상이 큼
- 처치 시 큰 particle burst와 camera shake 발생

## 조정 포인트

- 초반이 어렵다: `basic.hp`, 첫 웨이브 `count`, `spawn_interval`을 낮춘다.
- 중반이 밋밋하다: `fast`, `tank`, `exploder` 등장 웨이브를 앞당긴다.
- 후반 프레임이 낮다: 웨이브 수량보다 적 풀 크기, 총알 풀 크기, 아군 update throttling을 먼저 확인한다.
