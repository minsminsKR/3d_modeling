# 꼬마선충 커넥톰 시뮬레이션 (사이클롭스 몸체)

실제 꼬마선충(C. elegans) 커넥톰 — 뉴런 300개, 시냅스 연결 3,690건 — 을 브라우저에서
실시간으로 시뮬레이션하고, 그 운동 출력으로 이 레포의 사이클롭스 3D 모델을 움직이는
별도 웹 가상공간입니다. 무대는 잔디와 흙, 나무와 바위가 있는 자연 초원이며,
안쪽 나무와 바위는 코 촉각(회피)을 일으키는 장애물로 작동합니다.

사이클롭스 재질은 `model_test`에서 검증된 방식(MeshBasicMaterial + 원본 텍스처)을
사용합니다. Hunyuan3D 메시는 노멀이 불안정해 조명 기반 재질에서 검게 보일 수 있기
때문입니다.

## 실행 방법

외부 파이썬 패키지가 필요 없습니다 (표준 라이브러리만 사용).

```bash
python worm_sim/server.py --host 127.0.0.1 --port 8090
```

브라우저에서 `http://127.0.0.1:8090` 접속. (Three.js는 CDN에서 로드되므로 인터넷 연결 필요)

## 조작법

| 조작 | 동작 |
|---|---|
| 바닥 클릭 | 먹이 놓기 |
| 개체 클릭 | 선택 → 오른쪽 패널에 뉴런 발화 실시간 표시 |
| 마우스 드래그 / 휠 | 카메라 회전 / 줌 |
| 먹이 뿌리기 버튼 | 무작위 위치에 먹이 5개 |
| 개체 추가 버튼 | 원본 커넥톰을 가진 개체 생성 |
| 배속 버튼 | x1 → x2 → x4 |

## 작동 원리

### 뇌 (커넥톰)

- 데이터: Busbice/GoPiGo 커넥톰 (White et al. 1986 / Varshney et al. 2011 유래).
  `web/data/connectome.json` — 뉴런 300개 + 근육 세포 97개, 시냅스 항목 3,690건.
- 모델: 임계값 적분-발화(threshold integrate-and-fire). 세포별 누적 전위가
  임계값(30)을 넘으면 발화하여 연결된 세포에 가중치를 전파하고 자신은 리셋.
- 각 개체는 독립된 뇌 인스턴스를 초당 26스텝으로 실행. 개체당 연산량이 미미해
  개체 14마리 기준으로도 CPU 부하는 무시할 수준.

### 감각 입력 (가상공간 → 뉴런)

| 가상공간 이벤트 | 자극되는 뉴런 |
|---|---|
| 전방 장애물/접시 테두리 | FLP, ASH, IL1V, OLQ (코 촉각) |
| 먹이 농도 (거리 반비례 × 허기) | ADF, ASG, ASI, ASJ (화학감각) |

먹이 방향에 따라 좌/우 화학감각 클래스에 자극 편향을 줍니다.

### 운동 출력 (뉴런 → 사이클롭스)

원본 GoPiGo 로봇과 같은 방식으로 좌/우 몸통 근육(MDL/MVL vs MDR/MVR 07~23번)의
누적 활성값을 읽어:

- 합계 크기 → 이동 속도 (Walking 애니메이션 재생 속도 연동)
- 부호 → 전진/후진
- 좌우 비대칭 → 회전

여기에 먹이 방향으로의 약한 직접 조향(클리노택시스 반사 근사)을 55% 가중치로
혼합해 먹이 접근을 안정화했습니다. 회피·후진·자발적 방향 전환은 커넥톰에서
창발하는 행동입니다.

### 생존과 번식 (인공생명 규칙 — 생물학적 재현 아님)

- 에너지가 시간·이동량에 따라 감소하고, 먹이를 먹으면 회복. 0이 되면 사망.
- 성체(15초 이상) 두 개체가 에너지 68 이상으로 2.6m 안에서 만나면 자손 생성.
  자손의 커넥톰은 두 부모를 세포 단위로 교차하고 시냅스 가중치를 2% 확률로
  ±1 변이시킨 것 → 세대가 지나며 행동 특성이 조금씩 달라집니다.
- 공개 커넥톰은 자웅동체 기준이라 실제 짝짓기 신경회로는 존재하지 않으며,
  번식은 게임 규칙 레이어입니다.

## 파일 구성

```text
worm_sim/
  server.py              # 정적 서버 (모델/텍스처 경로 라우팅 포함)
  web/
    index.html
    styles.css
    data/connectome.json # 변환된 커넥톰 데이터
    src/
      connectome.js      # 적분-발화 시뮬레이터, 교배/변이
      agent.js           # 감각→뉴런, 근육→이동 매핑, 에너지/번식
      world.js           # 자연 초원 무대(잔디/흙/나무/바위), 먹이
      main.js            # 부트스트랩, 모델 로딩, UI, 루프
```

사이클롭스 모델은 `model_test/model/Cyclopse/mixamo/Walking.fbx`(+`Jump.fbx`),
텍스처는 `game/assets/characters/Cyclopse/source/model_textured.jpg`를 그대로 사용합니다.
