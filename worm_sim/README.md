# 꼬마싸이클롭충 — 꼬마선충 커넥톰 시뮬레이션

실제 꼬마선충(C. elegans) 커넥톰 — 뉴런 300개, 시냅스 연결 3,690건 — 을 브라우저에서
실시간으로 시뮬레이션하고, 그 운동 출력으로 이 레포의 사이클롭스 3D 모델을 움직이는
별도 웹 가상공간입니다. 무대는 잔디와 흙, 나무와 바위가 있는 자연 초원입니다.

개체들은 서로를 페로몬과 접촉으로 인식하며, 자웅동체는 자가수정으로 산란하고
수컷은 페로몬을 따라 짝을 찾아가 교배합니다. 유충은 작게 태어나 먹이를 먹으며
성체로 성장합니다.

## 실행 방법

외부 파이썬 패키지가 필요 없습니다 (표준 라이브러리만 사용).

```bash
python worm_sim/server.py --host 127.0.0.1 --port 8090
```

브라우저에서 `http://127.0.0.1:8090` 접속. (Three.js는 CDN에서 로드되므로 인터넷 연결 필요)

## 조작법

| 조작 | 동작 |
|---|---|
| 바닥 클릭 | 먹이 놓기 |
| 개체 클릭 | 선택 → 오른쪽 패널에 뉴런 발화 실시간 표시 |
| 마우스 드래그 / 휠 | 카메라 회전 / 줌 |
| 먹이 뿌리기 버튼 | 무작위 위치에 먹이 5개 |
| 개체 추가 버튼 | 원본 커넥톰을 가진 개체 생성 |
| 배속 버튼 | x1 → x2 → x4 |

몸 색: 원본색 = 자웅동체(⚥), 푸른색 = 수컷(♂). 유충은 작고, 먹으며 커집니다.

## 작동 원리

### 뇌 (커넥톰)

- 데이터: Busbice/GoPiGo 커넥톰 (White et al. 1986 / Varshney et al. 2011 유래).
  `web/data/connectome.json` — 뉴런 300개 + 근육 세포 97개, 시냅스 항목 3,690건.
- 모델: 임계값 적분-발화(threshold integrate-and-fire). 세포별 누적 전위가
  임계값(30)을 넘으면 발화하여 연결된 세포에 가중치를 전파하고 자신은 리셋.
- 각 개체는 독립된 뇌 인스턴스를 초당 26스텝으로 실행.

### 감각 입력 (가상공간 → 실제 감각 뉴런)

| 가상공간 이벤트 | 자극되는 뉴런 | 실제 생물학 근거 |
|---|---|---|
| 전방 장애물(나무·바위)/경계 | FLP, ASH, IL1V, OLQ | 코 촉각 회피 반사 |
| 먹이 농도 (거리 반비례 × 허기) | ADF, ASG, ASI, ASJ | 화학주성 |
| 다른 개체의 페로몬 (유인) | ASK | 아스카로사이드 유인, 군집·짝 찾기 |
| 페로몬 과밀 (기피) | ADL | 고농도 아스카로사이드 기피 |
| 개체 간 접촉 | ALM, AVM, PLM | 몸통 부드러운 촉각 (접촉 순간만 자극 = 습관화 근사) |

### 운동 출력 (뉴런 → 꼬마싸이클롭충)

좌/우 몸통 근육(MDL/MVL vs MDR/MVR 07~23번) 누적 활성값에서:

- 합계 크기 → 이동 속도 (Walking 애니메이션 재생 속도 연동, 유충은 더 느림)
- 부호 → 전진/후진
- 좌우 비대칭 → 회전 (창발적)

여기에 목표물(먹이/짝/군집) 방향의 클리노택시스 반사를 우선순위에 따라 혼합합니다:
장애물 회피 > 배고픔·먹이 > 수컷 짝 찾기 > 과밀 이탈 > 약한 군집 유인.

### 생활사 (실제 생물학 기반)

- **성장**: 유충으로 작게 태어나(크기 15%) 먹이를 먹으며 성체(80% 이상)로 성장.
  실제 L1~L4 유충 단계의 근사. 유충은 번식 불가.
- **자웅동체(⚥) 자가수정**: 실제 꼬마선충의 주 번식 방식. 성체가 에너지를 충분히
  모으면 단독으로 산란 (자손 = 자기 커넥톰 + 변이).
- **수컷(♂) 교배**: 실제 수컷은 자웅동체가 내는 페로몬을 ASK 뉴런으로 감지해
  찾아갑니다. 교배 시 자손 커넥톰은 두 부모를 세포 단위로 교차 + 시냅스 가중치
  2% 확률 ±1 변이. 자손 성별은 수컷 20% (실제는 ~0.1%지만 관찰 가능하게 상향).
- **사망**: 에너지가 0이 되면 사망.

## 파일 구성

```text
worm_sim/
  server.py              # 정적 서버 (모델/텍스처 경로 라우팅 포함)
  web/
    index.html
    styles.css
    data/connectome.json # 변환된 커넥톰 데이터 (감각 그룹 포함)
    src/
      connectome.js      # 적분-발화 시뮬레이터, 교배/변이
      agent.js           # 감각→뉴런, 근육→이동, 페로몬/접촉/성장/번식
      world.js           # 자연 초원 무대(잔디/흙/나무/바위), 먹이
      main.js            # 부트스트랩, 모델 로딩, UI, 루프
```

사이클롭스 모델은 `model_test/model/Cyclopse/mixamo/Walking.fbx`(+`Jump.fbx`),
텍스처는 `game/assets/characters/Cyclopse/source/model_textured.jpg`를 그대로 사용합니다.
재질은 `model_test`에서 검증된 방식(MeshBasicMaterial + 원본 텍스처)을 사용합니다 —
Hunyuan3D 메시는 노멀이 불안정해 조명 기반 재질에서 검게 보일 수 있기 때문입니다.
