# 마지막 출석 — 개발판 플레이 안내

2026-10-03 기준 개발 중인 **소스 버전**의 안내입니다. 기존 Windows 빌드는 최신 UI·재질·은밀 이동 변경을 포함하지 않습니다. 이번 변경의 새 실행 파일과 Unity 플레이 검수는 아직 없으며, 상용 완성판이 아닙니다. 최신 범위와 출시 차단 항목은 `STEALTH_UPGRADE.md` 및 `RELEASE_READINESS.md`를 확인하세요.

`Builds/Windows/HappyToyV2.exe`를 실행합니다. 실행 파일만 따로 옮기지 말고 Windows 폴더 전체를 함께 보관하세요.

시작 화면에서 ‘학교에 들어가기’ 또는 Enter로 시작합니다. 환경 설정에서 음량과 마우스 감도를 조절할 수 있습니다.

브라우저 URL이 아니라 Windows 실행 파일로 플레이합니다. 기존 별도 `UnityV2` 폴더의 실행 파일은 이전 빌드이므로 이 프로젝트의 `Builds/Windows`를 사용하세요. 빌드 결과물은 Git에 포함하지 않습니다.

## 조작

- WASD: 이동 / 마우스: 시선
- Shift: 달리기. 숨이 줄어들며, 멈추거나 걸으면 회복됩니다.
- C 또는 Ctrl: 낮은 자세 전환. 걸음 속도가 55%가 되고 발소리가 줄어듭니다. 머리 위가 막혀 있으면 일어나지 않습니다. 낮은 자세에서는 Shift로 달릴 수 없습니다.
- E: 화면 중앙에 표시되는 대상 조사, 문 조작, 은신처 출입
- F: 손전등 / Esc: 일시정지·계속하기 / J: 조사 기록 열기·닫기
- Q: 폭죽 던지기. 새 탐색에 2개이며, 이미 추격 중인 적을 즉시 떼어내는 도구는 아닙니다.

조사 기록에는 발견한 단서만 표시됩니다. 일시정지와 기록 열람 중에는 게임과 효과음이 멈춥니다. ‘처음부터 다시 시작’과 ‘시작 화면으로’는 현재 탐색 기록을 초기화합니다.

복도의 하교 당번표와 교실의 자리표를 E로 조사하면 J 기록창의 아래쪽에 내용이 남습니다. 같은 게시물을 다시 읽어도 중복 저장되지 않으며, 필수 이야기 진행에는 영향을 주지 않습니다. 기록은 이번 플레이 동안만 유지되며 게임을 종료한 뒤 이어하기는 지원하지 않습니다.

환경 설정에서 음량은 5% 단위로, 마우스 감도는 버튼으로 조절합니다. ‘저장하고 돌아가기’ 또는 Esc로 나가면 이 PC에 저장됩니다. 메뉴에서는 Enter가 현재 선택된 버튼을 실행합니다.

숨이 소진되면 달리기가 멈춥니다. 숨을 25% 이상 회복하고 Shift를 놓았다가 다시 누르면 재개할 수 있습니다. 소진 중에는 숨 막대 색과 안내 문구가 바뀝니다. Shift를 계속 누르고 있어도 달리기가 자동으로 반복되지 않습니다.

화면 중앙 점이 금색이면 조사 가능한 대상입니다. 슬라이딩 문은 열린 뒤에도 문틀의 고정 손잡이로 닫을 수 있습니다.

문은 양쪽으로 열리며, 문 사이에 서 있으면 닫히지 않습니다.

## 목표와 생존

교실 출석부에서 시작해 화면의 조사 지시를 따라 지워진 하교 기록을 복원하세요. 모든 기록을 돌려놓은 뒤 처음 들어온 현관의 출석함으로 돌아갑니다.

적의 발소리는 위치와 거리에 따라 들립니다. 계속 달리기보다 문을 닫아 시야를 끊고 숨을 회복하는 것이 중요합니다. 적이 숨는 순간을 보았다면 은신처도 안전하지 않습니다. 가까이 다가온 적의 낮은 공격음이 들리면 즉시 거리를 벌리세요.

물에서는 발소리가 더 멀리 퍼집니다. 낮은 자세와 손전등 끄기는 아직 들키지 않았을 때 발견을 늦추지만, 시작된 추격을 바로 없애지는 않습니다. 벽이나 문으로 시선을 끊은 뒤 다른 길로 이동하세요. 화면의 ‘내 발소리’는 최근 자신이 낸 소리의 크기이며, 적이 실제로 들었는지를 알려주는 표시가 아닙니다. 마네킹은 기존의 시선·손전등 규칙을 유지합니다.

공격에는 약 0.75초의 예고가 있습니다. 옆으로 피했다가 너무 일찍 되돌아오면 맞을 수 있습니다. 공격이 빗나간 뒤 짧은 회복 시간에 지나가세요.

보건 기록을 읽으면 V1 Hwacat 액자 이벤트가 시작됩니다. 인형이 변신하는 동안 출구를 확보하세요. 방 안에서 변신이 끝날 때까지 쉬면 위험합니다. 모든 기록을 준비함에 돌려놓으면 두 적의 위협이 멈춥니다.

죽거나 탈출한 뒤에는 화면의 ‘다시 시작’으로 새로 플레이할 수 있습니다.

## 개발판 한계

### 수동 성능 검토

직접 플레이를 기록하려면 프로젝트의 `Tools/Run-PlayReview.ps1`을 PowerShell에서 실행하세요. 게임 창이 열리며 자동 이동은 하지 않습니다. 정상 진행으로 교실·화장실·보건실과 추적 구간을 플레이한 후 게임 메뉴에서 종료하면 `Verification/ManualRuns/시간/`에 로그와 `manual-timing.json`이 남습니다. 일반 실행에는 이 기록 기능이 켜지지 않습니다.

이 진단은 포커스가 있는 실제 플레이 중 메인 카메라의 렌더 콜백 간격을 기록합니다. 메뉴·포커스 전환 구간은 제외하며, 충분한 구간이 없으면 `enoughSamples`가 false입니다. GPU 처리 시간이나 디스플레이의 실제 표시 FPS를 직접 측정하는 도구는 아닙니다. 해상도가 바뀐 기록도 별도로 구분해야 합니다.

본관·별관·2층 액자실·지하 침수 구역을 잇는 개발 중인 공포 게임입니다. 시작·일시정지·조사 기록·설정·결과 화면과 7개 필수 기록의 복원·탈출 흐름이 있습니다. 저장/이어하기, 게임패드, 몬스터 아트·동작 마무리, 음향 믹싱, 전체 생존 난이도와 새 Windows 빌드는 아직 출시 기준을 충족하지 않았습니다. 이전 검증 결과를 최신 버전의 실제 플레이 성공으로 해석하지 않습니다.
