# 회랑의 책상과 수납 선반

회랑의 목재·종이 벽과 어울리는 낡은 서랍 책상, 큰 기록 선반, 필기 도구,
폭죽 묶음과 배터리 팩을 Blender에서 직접 제작했다. 실제 목재 이음새,
둥근 모서리, 황동 손잡이, 속이 빈 서랍과 도자기, 책의 표지·페이지·라벨을
모델링하며 기존의 귀속 정보가 있는 PBR 표면을 재사용한다.

## 배치와 조사

시드마다 책상 12개와 선반 6개를 회랑의 입구, 보급 방과 기억 방 벽에 배치한다.
문과 문짝의 이동 범위, 캐비닛 출입구, 촛불, 봉인 제단과 다른 가구의 공간을
피한다. 정적인 가구와 열린 서랍의 최대 범위는 적의 길찾기에도 반영한다.

기존 폭죽 8개 중 4개는 책상 위, 4개는 서랍 안에 놓인다. `E`로 서랍을 열고
안의 폭죽을 조준해 다시 `E`로 수집한다. 닫힌 서랍의 내용물은 조준하거나
수집할 수 없다. 선반에는 기존 배터리 6개를 배치한다. 소모품 수량이나
아이템의 저장 식별자는 늘리지 않는다. 장부·원고·붓·벼루·두루마리와 도자기는
가구 위에 놓인 실제 장식 모델이다.

서랍은 실제 제작한 파트와 충돌체가 함께 미끄러지며 몸이나 다른 물건이
이동 범위를 막으면 멈춘다. 일시정지는 현재 동작을 멈추고, 동작 감소에서는
즉시 전환한다. 중단 저장은 서랍의 열림 상태와 이동 거리도 기록한다.
이전 저장 형식의 소모품 상태도 유지하며 서랍은 닫힌 상태로 시작한다.
수집한 아이템은 서랍을 다시 열거나 이어하기를 해도 생기지 않는다.

## 제작 원본과 재현

`SourceArt/CorridorFurnishings/README.md`에 Blender **4.0.2** 제작·검증 명령을
기록했다. 같은 폴더의 generator, validator, manifest와 `Models/*.blend` 5개를
함께 전달한다. FBX 5개와 Unity `.meta`는 `Assets/Resources/CorridorFurnishings`에
있다. 기존 PBR 이미지 링크는 프로젝트 상대 경로이며 추가 플러그인은 필요하지
않다. 원본 모델의 CC0 조건과 재사용 표면의 기존 크레딧을 보존한다.

Unity **6000.6.0f1**에서 `CorridorFurnitureImport.Ensure`가 단위, 노멀·탄젠트,
계층, 재질과 물리 없는 모델 import를 재현한다. `QualityValidation.BuildWindows`
도 이 설정을 적용한다. 원래 학교 씬은 변경하지 않는다.

## 검증 범위

`CorridorFurnitureAssetTests`는 모델의 실제 크기와 메시·UV·노멀·독립 서랍을
확인한다. `CloudCorridorFurnitureTests`는 실제 회랑의 길찾기, 문과 캐비닛,
마우스 조준과 `E` 조사, 유한 보급품, 새·이전 저장 복원을 검사한다.
제작 모델의 studio 이미지와 실제 손전등을 켠 생산 카메라 화면은 별도로
점검한다. 요약은 `Verification/corridor-furnishings/summary.json`에 기록하며
반복 빌드·로그·검토 이미지는 선택적인 로컬 검증 자료다.
