# Creature source and provider notices

The original and rigged models were generated through the project modeling webapp. `generation-jobs.json`, each original GLB and the reference provenance document the exact source. The game meshes, body plans, weights, own actions and authoring tools were authored for this project. No generator model weights or vendor runtime caches are bundled here.

`license-provenance.json` records the upstream revisions pinned by `hunyuan3d-webapp/upstream/pins.json`, the original license links and SHA256 of the retained license texts in `licenses/`: Tencent Hunyuan3D 2.1, Microsoft TRELLIS.2 and VAST-AI-Research SkinTokens. These notices describe the generating tools; they do not relicense user references or automatically license every generated asset under MIT/CC0. Refer to the retained provider terms when setting up generation.

Uncat/Baby references were created with the built-in image generator; their exact prompts are in `concept-prompts.json`. Cyclopse starts with the user-supplied round creature image, retained as `user-reference-round-cyclopse.png`; its owner retains reference rights. `reference-standing-provenance.json` records the standing reference transformation. No independent reference license grant was supplied.

The locally fitted final rigs and own in-place actions do not contain animations downloaded from Mixamo or another character asset. Blender 4.0.2 and the pinned Python dependencies are installed authoring tools; their software notices remain with those installations.
