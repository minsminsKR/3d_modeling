# 백수귀 질주 미리보기

이 도구는 수정한 실제 GLB 메시, 스킨 및 애니메이션을 Three.js r164로 재생한다.
소리나 오디오 장치를 생성하지 않는다. 모델 생성·리깅용 웹앱과는 별개의 선택적
로컬 검토 도구이며 Unity 게임 파일을 변경하지 않는다.

## 실행

Python 3.10 이상으로 이 디렉터리의 `preview_server.py`를 실행한다.
외부 라이브러리를 설치할 필요는 없다.

```powershell
python preview_server.py --port 8061
```

브라우저에서 <http://127.0.0.1:8061/>을 연다. 서버는 루프백에만 바인딩된다.
포트가 이미 사용 중이면 다른 `--port`를 지정한다. 종료는 Ctrl+C이다.
Windows에서 백그라운드로 실행하는 경우 `Start-Process -WindowStyle Hidden`을
사용한다.

모델 파일은 이 디렉터리에 두며 다음 이름을 인식한다.

| 파일 | 용도 |
| --- | --- |
| `Baeksugwi_Run.glb` | 내보낸 실제 전체 품질 모델 |
| `previews/Baeksugwi_Run_Preview.glb` | 선택적 2K 텍스처 미리보기 파생 파일 |

2K 파일이 있으면 먼저 사용한다. 메시와 애니메이션은 실제 파일의 내용을
그대로 재생하며 텍스처 해상도만 줄인 파생본이어야 한다. 모델 선택 메뉴에서
전체 품질을 선택할 수 있다. `?model=Baeksugwi_Run.glb`로 전체 모델을 직접
선택할 수도 있다.

기본 모션은 `Run_InPlace`이며 `Run_Forward`가 있다면 선택 메뉴에 표시한다.
앞으로 이동하는 모션에서는 모델의 루트 이동을 카메라가 따라간다. 반복 지점에서
루트 위치가 돌아오는 것은 한 주기 GLB의 재생 방식이다. 바닥 격자는 주행 속도에
맞춰 이동하므로 제자리 모션에서도 전진 방향을 확인할 수 있다. 재생 배속은
모션 속도에만 적용한다. 실제 게임 이동 속도를 바꾸지 않는다.

접지면은 `skeleton-plan.json`의 glTF Y 좌표 `floor`를 사용한다. 쉬고 있는
원본 메시의 가장 낮은 점은 질주 중 손바닥 접지면과 다를 수 있으므로
원본 경계 상자의 최솟값으로 바닥을 정하지 않는다.

왼쪽 마우스로 드래그하면 회전, 휠은 확대/축소, 오른쪽 드래그는 시점 이동이다.
두 손가락으로 화면을 집으면 확대/축소할 수 있다. 처음 시점과 정면·옆면 시점을
버튼으로 선택할 수 있으며 뼈대와 와이어프레임 표시를 켜서 스킨을 확인할 수 있다.
좁은 브라우저에서는 하단 재생 바만 표시한다. `설정`을 누르면 최대 화면 높이의
35%인 스크롤 가능한 설정이 펼쳐진다. 기본 카메라는 좁은 화면의 가로 폭과
하단 재생 바를 고려하여 머리와 손이 모두 보이도록 맞춘다.

## 의존성

저장소의 `game/happy_toy/vendor/three`에 이미 포함된 Three.js r164의
`three.module.js`, `GLTFLoader.js`, `BufferGeometryUtils.js`를 재사용한다.
이는 Three.js Authors의 MIT 라이선스 소프트웨어이다. 서버는 이 지정된
의존성 디렉터리와 현재 미리보기 디렉터리를 제공한다. CDN, 외부 서비스,
워크스테이션 절대 경로에 의존하지 않는다.

모델에 DRACO/KTX2/Meshopt 압축을 새로 적용하면 해당 공식 디코더를 함께
벤더링하도록 확장해야 한다. 현재 Blender의 기본 비압축 GLB를 사용한다.
