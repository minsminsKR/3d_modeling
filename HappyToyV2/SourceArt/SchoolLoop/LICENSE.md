# School loop source and asset provenance

The school plan/visual target is the image supplied by the user for this project.
Its unchanged input and provenance are preserved under `References/`.

The new piano and music stand were generated in the user's designated,
self-hosted `hunyuan3d-webapp` using TRELLIS.2. Each asset folder records its actual
completed/saved job, options, exact reference/prompt, processed input and original
GLB/PBR. The bundled game meshes and editable Blender sources derive from those
preserved originals. No third-party piano or score model was downloaded.

The TRELLIS.2 upstream tool notice is preserved at
`../CorridorEntrance/TRELLIS.2-LICENSE.txt`. Existing authoring recipes, the
classroom chair source and physical PBR resources remain part of the repository;
their attribution continues through `ThirdParty/Graphics/manifest.json` and
`Graphics-Credits.txt`. New C#/Python finishing and layout code belongs to this
project's source handoff. Generation-tool notices are not a substitute for
asset provenance or a representation about exclusive rights.
