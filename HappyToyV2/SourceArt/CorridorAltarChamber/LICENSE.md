# Original art and reused sources

The new chamber model geometry, procedural chalkboard pixels, shader-independent
stain silhouettes and authoring scripts in this directory were originally
authored for HappyToyV2. The original art is released under **CC0-1.0**:
https://creativecommons.org/publicdomain/zero/1.0/

The new models reuse existing repository PBR Resources. Real scanned wood,
plaster and iron surfaces come from the attributed Poly Haven CC0 sources
already recorded under `ThirdParty/Graphics` and
`SourceArt/GraphicsUpgrade/pbr-source-manifest.json`; their license and author
credits remain authoritative. Original paper, enamel, brass and microscopic
fibre surfaces reuse `SourceArt/GraphicsUpgrade`'s documented original sources.

The original chalk lettering uses glyph outlines from the repository's bundled
OFL Korean font. Preserve `Assets/Resources/Fonts/OFL.txt` and `SOURCE.txt` when
distributing that font. The displayed attendance/ritual lesson is original text.

No third-party mesh, reference photograph, stock portrait or unlicensed texture
was added. Existing authored school desks/chairs, corridor archive shelf,
writing set and lantern are reused as licensed original project geometry; their
editable Blender sources and generators remain in the repository.
