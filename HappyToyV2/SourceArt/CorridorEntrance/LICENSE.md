# Asset origin and licenses

The temple-gate and cave-rock references are original generated project images.
Their prompts, generator settings and exact uploaded inputs are preserved with
each asset's provenance. The base meshes and embedded PBR were generated through
the repository's designated modeling webapp; `job.json` and `provenance.json`
identify the actual backend, settings and source files. No third-party game model
or reference artwork is supplied as part of this bundle.

The local finishing script, editable Blender sources and Unity integration are
HappyToyV2 project authoring work. Preserve their source and these origin records
with the resulting game assets under the repository's applicable project terms.

The modeling backend and Blender retain their own tool licenses. The selected
backend must be read from the saved job/provenance; its tool license does not by
itself assign a different license to these generated outputs. Repository setup
and backend-license references are in `hunyuan3d-webapp/INSTALL-A100.md` and its
checked-in third-party notices. Blender is distributed separately under its
own license. Do not remove existing third-party notices for any reused resources.

`TRELLIS.2-LICENSE.txt` preserves the repository's existing Microsoft MIT notice
for the TRELLIS.2 backend used to generate these assets. It is a tool notice;
the asset origin and project permissions above remain separately documented.
