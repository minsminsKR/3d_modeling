# 개인용 플레이 개선

현재 목표는 직접 즐길 수 있는 학교 공포 게임의 재미, 조작 이해도와 분위기를
높이는 것이다. 상업 출시나 배포 심사를 전제로 하지 않는다. 기존 실행 가능한
빌드를 유지하면서 작은 플레이 개선을 검증해 나간다.

## 이번 변경: 폭죽과 은신 피드백

- 폭죽의 첫 폭발 프레임에 같은 소리가 두 번 재생되던 경로를 하나로 통합
- 은신 중, 재사용 준비 중, 소진, 이야기 복원 후의 Q 입력 실패 이유를 짧은
  전용 HUD에 표시. 회수한 기록/이야기 안내문은 덮어쓰지 않음
- 제목/일시정지에서는 Q가 아무 행동이나 새 피드백을 만들지 않음
- 기존 2개 수량, 물리 투척, 1.2초 도화선, 10초 연소, 추격 중 적을 유인하지
  못하는 규칙은 유지. 제목/일시정지 조작 안내에 추격 전 유인 용도를 명시
- 움직임 완화 설정은 도화선 회전과 빠른 빛 깜빡임을 억제. 일시정지 중
  설정을 바꿔도 밝은 순간이 화면에 고정되지 않게 처리
- 은신 HUD의 무조건적인 ‘기다리세요’를 중립적인 듣기/이동 안내로 변경
- 실제로 목격된 은신처의 문 앞에서 공격이 시작될 때만 짧은 경고와 별도의
  공간 문소리를 제공. 벽 너머 적의 인식 상태나 유인 성공 여부는 표시하지 않음
- 경고는 해당 은신처에서 들은 실제 공격 이벤트의 짧은 기억이며, 다른 은신처나
  재시작으로 전파하지 않음. 음량/일시정지 설정과 기존 공격 예고 시간을 유지

## 검증 범위

기존 21개 Unity 검사와 생존 경로를 유지하고 폭죽 사례 3개를 더해 총 24개를
준비했다. 캐비닛 사례에는 실제 HUD 캡처, 한 공격당 한 효과음, 일시정지와
재시작 정리를 추가했다. HUD 캡처 중에는 읽어오는 순간만 정지하고, 이후
기존 공격 시계를 다시 진행해 실제 실패/재시작 동작도 검사한다.

현재 이 변경은 소스/외부 API 컴파일 검사를 마쳤고 **새 Unity 실행은 대기 중**이다.
마지막으로 실제 검사를 통과한 실행본은 소스 `9230608`의 UBA #8이다.
자동 검사가 사람의 공포감/재미를 대신하지는 않지만, 그 한계를 이유로
플레이 개선을 멈추지는 않는다. 실제 결과는 `CLOUD_QA.md`에 별도로 기록한다.

이전의 상업 배포 준비 작업은 이번 플레이 패치와 분리해 보존했다. 고지/출시
프로필/권리 확인 서류를 개인용 플레이 빌드의 선행 조건으로 요구하지 않는다.
