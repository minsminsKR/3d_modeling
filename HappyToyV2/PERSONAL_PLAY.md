# 개인용 플레이 개선

현재 목표는 직접 즐길 수 있는 학교 공포 게임의 재미, 조작 이해도와 분위기를
높이는 것이다. 상업 출시나 배포 심사를 전제로 하지 않는다. 기존 실행 가능한
빌드를 유지하면서 작은 플레이 개선을 검증해 나간다.

## 실제 플레이 피드백 후속: 구현 완료, 새 엔진 검증 대기

사용자가 #9를 직접 플레이하고 지적한 여섯 가지를 다음과 같이 수정했다.
아래는 새 소스의 구현 범위이며 아직 #9 실행본에 들어 있지 않다.

1. 캐비닛의 검정 장식 틈을 실제 문 두께를 관통하는 구멍으로 수정. 원래
   31개 하위 메시 이름/기준점과 충돌 상자 4개는 유지하고, 숨을 때 바깥을
   향하는 고정 눈높이를 사용한다. 웅크린 자세는 나올 때 복원한다.
2. 사이클롭스를 보이는 복도에 켜는 대신 벽 뒤의 안전한 위치를 확인하고
   실제 NavMesh를 따라 0.85m/s로 코너를 돌아 걷게 한다. 도착 후 포효하며
   플레이어 조작은 유지한다. 플레이어가 코너에 서 있으면 강제로 나타나지
   않고, 이동한 뒤 안전한 배치를 다시 확인한다.
3. 실제 시야로 발각되는 순간 짧은 노이즈와 제한된 효과음을 제공한다.
   벽/층 너머의 인식 상태를 보여주지 않고, 중복 발각은 4초간 합치며
   0.8초 후 화면을 비운다. 움직임 완화 설정에서는 움직이는 노이즈 없이
   약한 가장자리 변화와 낮은 효과음만 사용한다.
4. 음악실 피아노의 검은 건반·악보대·페달과 벤치 다리, 세 줄의 좌석/악보대,
   벽걸이 타악 교구를 보강한다. 추가 좌석 두 개와 악보대에는 기존과 같은
   충돌 및 좁은 NavMesh 장애물을 두고, 원래 통로/기록/캐비닛 접근을 검사한다.
5. 통로 위에 떠 있던 합창 판과 2층/지하/준비실 표지를 실제 벽과 액자형
   받침에 맞춘다. 원래 기록/상호작용 식별자는 유지한다.
6. 지속적인 손전등 켜짐/꺼짐 표시와 토글 자막을 없앤다. F 조작 안내,
   실제 조명 전환 및 스위치 소리는 유지한다.

장면 전체를 재생성하지 않았다. 원본 장면/메타/빌드 선택은 그대로이며
별도 백업도 보존했다. 방 배치는 이 장면만 대상으로 한 런타임 보강이고,
캐비닛 모델만 기존 제작 스크립트로 다시 내보냈다.

새 Unity 검사 정의는 기존 24개를 유지한 총 **33개 (EditMode 6 + PlayMode 27)**다.
캐비닛 실제 카메라 6장, 코너 등장 4장, 방 배치 5장과 발각 UI 2장을 준비했다.
이는 아직 실행 결과가 아니다. 기존 엄격한 생존/오디오 검사도 그대로 실행한다.

## #9에 포함된 이전 변경: 폭죽과 은신 피드백

- 폭죽의 첫 폭발 프레임에 같은 소리가 두 번 재생되던 경로를 하나로 통합
- 은신 중, 재사용 준비 중, 소진, 이야기 복원 후의 Q 입력 실패 이유를 짧은
  전용 HUD에 표시. 회수한 기록/이야기 안내문은 덮어쓰지 않음
- 제목/일시정지에서는 Q가 아무 행동이나 새 피드백을 만들지 않음
- 기존 2개 수량, 물리 투척, 1.2초 도화선, 10초 연소, 추격 중 적을 유인하지
  못하는 규칙은 유지. 제목/일시정지 조작 안내에 추격 전 유인 용도를 명시
- 움직임 완화 설정은 도화선 회전과 빠른 빛 깜빡임을 억제. 일시정지 중
  설정을 바꿔도 밝은 순간이 화면에 고정되지 않게 처리
- 은신 HUD의 무조건적인 ‘기다리세요’를 중립적인 듣기/이동 안내로 변경
- 실제로 목격된 은신처의 문 앞에서 공격이 시작될 때만 짧은 경고와 별도의
  공간 문소리를 제공. 벽 너머 적의 인식 상태나 유인 성공 여부는 표시하지 않음
- 경고는 해당 은신처에서 들은 실제 공격 이벤트의 짧은 기억이며, 다른 은신처나
  재시작으로 전파하지 않음. 음량/일시정지 설정과 기존 공격 예고 시간을 유지

## 검증 범위

기존 21개 Unity 검사와 생존 경로를 유지하고 폭죽 사례 3개를 더해 총 24개를
준비했다. 캐비닛 사례에는 실제 HUD 캡처, 한 공격당 한 효과음, 일시정지와
재시작 정리를 추가했다. HUD 캡처 중에는 읽어오는 순간만 정지하고, 이후
기존 공격 시계를 다시 진행해 실제 실패/재시작 동작도 검사한다.

이 변경은 소스 `7c13e7f`의 **UBA #9에서 실제 24개 검사와 Windows 빌드를
모두 통과**했다. 원본 XML의 EditMode 6/6 + PlayMode 18/18, 실패/건너뜀 0을
확인했고, 원본 ZIP 186항목의 CRC와 새 생산 코드를 검사했다. ZIP 전체를
압축 해제한 뒤 루트의 `HappyToyV2.exe`를 실행한다. 기존 #8도 보존한다.
자동 검사가 사람의 공포감/재미를 대신하지는 않지만, 그 한계를 이유로
플레이 개선을 멈추지는 않는다. 실제 결과는 `CLOUD_QA.md`에 별도로 기록한다.

이전의 상업 배포 준비 작업은 이번 플레이 패치와 분리해 보존했다. 고지/출시
프로필/권리 확인 서류를 개인용 플레이 빌드의 선행 조건으로 요구하지 않는다.
