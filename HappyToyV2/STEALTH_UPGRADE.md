# 은밀 이동과 소리 추적 — 2026-10-03

이번 단계는 기존 학교 공간을 보존하면서 **관찰 → 조용히 이동 → 들키면 시선 끊기 → 소리로 우회**를 실제 게임 규칙으로 연결한다. 그림자복도의 긴장 요소를 참고한 독자적인 학교 공포 게임 개발이며, 외부 게임의 자산·이야기를 복사하지 않는다.

## 바뀐 플레이

- C/Ctrl로 낮은 자세 전환. 실제 CharacterController 높이와 눈높이가 내려가며 보행 속도는 기본의 55%다. Shift가 낮은 자세를 해제하지 않는다
- 머리 위에 장애물이 있으면 서기를 거부하고 이유를 알린다. 발 위치를 유지하며, 은신처에서 나올 때 현재 자세의 실제 캡슐을 검사한다
- 적은 ‘Shift가 눌렸는지’ 대신 실제 발소리가 난 위치를 조사한다. 가만히 있거나 벽에 막혀 달리는 동안 새 발 접촉이 없으면 계속 소음을 내지 않는다
- 청각 범위는 건조/물 순서로 낮은 자세 **1.75/3.5m**, 걷기 **4/7m**, 달리기 **10/14m**다. 같은 층에서 범위 내 완전한 NavMesh 경로가 있어야 조사한다. 이는 음향 물리 시뮬레이션이 아니라 명시적인 게임 규칙이다
- Stalker와 등불 가면이 시선을 얻자마자 추격하지 않고 인식 정도를 쌓는다. 거리·낮은 자세·손전등·달리기에 따라 시간이 달라지고, 가려지면 서서히 잊는다. 짧은 한 프레임의 끊김만으로 즉시 초기화되지 않는다
- 인식 중 적이 플레이어를 향해 돌아서는 시각적 신호를 제공한다. 벽 뒤 적을 알려주는 전역 감지 표시나 성공 보장은 없다
- 추격이 시작되면 자세/손전등 전환만으로 놓치지 않는다. 기존 시야·마지막 목격 위치·추격 기억을 유지한다. 공격 예고·회복·가림·방향 회피 규칙도 유지한다
- 플레이 HUD에는 자신의 최근 발소리 크기와 손전등 상태를 표시한다. 적이 들었는지/발견했는지의 숨은 상태는 노출하지 않는다
- 마네킹의 시선·손전등 규칙은 그대로이며, 모든 적을 동일하게 바꾸지 않는다

## 수명 주기와 안전 장치

- 낮은 자세와 소음은 일시정지/결과/타이틀에서 진행하지 않는다
- 적의 발소리 이벤트 구독은 활성화·플레이어 교체·비활성화에 맞춰 정리한다
- 폭죽은 여전히 진행 중인 추격/공격을 취소하지 않는다. 아직 인식하지 못한 플레이어와 기하학적 시선이 겹쳤다는 이유만으로 유인을 무시하지 않도록 정리한다
- 등불 가면은 변신이 끝날 때 벽 너머/숨은 플레이어의 새 위치를 읽지 않고 마지막으로 확인한 위치를 유지한다
- 숨는 장면의 목격도 실제 인식된 추격과 시야를 기준으로 판정한다

## 검증

최종 소스 정적 검사 C# 85개·GUID 850개·검사 계약 12개, Python 검증기 테스트 24개, 실제 C# 상태 검증 117개(공격 29 + 물결 20 + 은밀 이동 68)가 통과했다. 공식 Unity 6000.6 및 대응 패키지 API를 참조한 외부 컴파일은 런타임 61개·Editor 소스 24개와 Linux/Windows 런타임 구성 모두 오류 0개다. 기존 경고는 남아 있다. 보고서에 각 소스 SHA-256과 최종 일치 여부를 기록했다.

최종 소스의 실행 결과는 `Verification/quality-stealth/`에 기록한다. 실제 C# `StealthRules`를 기존 공격·물결 테스트와 함께 실행하며, 인식 누적/상실·일시정지·비정상 입력·긴 프레임·자세 전환 및 여섯 소음 범위를 검사한다.

새 명시 실행 옵션 `-v2-stealth-output <directory>`는 실제 입력과 물리를 사용하는 낮은 자세/머리 공간/눈높이/걷기 소음/벽에 막힌 달리기/일시정지 검사를 제공한다. 저장 씬을 수정하지 않는 임시 검사 공간을 쓰며, 아직 **NOT RUN**이다. 준비된 Windows 검사 실행기는 `-Audit stealth`로 선택할 수 있다.

Unity 프로젝트 임포트·Play Mode·실제 화면/음향·NavMesh 통합·생존 밸런스·새 Windows 빌드는 이번 클라우드 작업에서 검증하지 못했다. 외부 Unity API 참조 컴파일은 이 검증들을 대체하지 않는다. 수치는 실제 플레이에서 조정할 초기값이며 ‘출시 가능한 난이도’라는 뜻이 아니다.
