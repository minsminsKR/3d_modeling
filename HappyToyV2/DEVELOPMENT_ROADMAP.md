### 1. 몬스터의 문 열기·닫기

- 몬스터도 실제 문을 열고 닫을 수 있게 한다. 순찰·소리 조사·추격 중 닫힌 문을 만났을 때 문을 조작하고 통과하는 흐름을 연결한다.
- 플레이어와 같은 실제 문짝·이동·충돌·문소리를 사용한다. 문을 무시하고 통과하거나 순간적으로 위치를 옮기지 않는다.
- **완료 기준:** 순찰·조사·추격에서 문 열기와 닫기를 모두 확인하고, 플레이어와 동시에 조작하거나 통로가 막힌 상황에서도 교착·관통·소리 중복이 없다.
- **관련 위치:** `StalkerBrain`, `Interactable`, `InteractionAudio`, 실제 이동 문짝과 NavMesh 접근 처리.

### 2. 추격 중 캐비닛 은신: 생존 75% / 사망 25%

- 쫓기는 상황에서도 캐비닛에 성공적으로 들어가면 **75% 확률로 생존하고 25% 확률로 사망**하는 규칙을 적용한다.
- 몬스터가 들어가는 모습을 봤다는 이유로 무조건 사망하는 기존 은신 처리가 있다면 이 요구사항으로 교체한다. 조용히 숨은 상황은 추격 중 확률 판정과 구분한다.
- 판정은 성공한 은신 진입 한 번당 한 번만 한다. 여러 적·여러 프레임·일시정지·중단 저장 복원 때문에 재추첨하거나 확률이 누적되지 않게 한다.
- **완료 기준:** 제어 가능한 난수로 생존·사망 분기를 각각 검증하고, 충분한 반복 표본에서 75/25 분포를 확인한다. 기존 확정 사망을 전제한 검증도 새 계약에 맞춘다.
- **관련 위치:** `PlayerMotor`, `StalkerBrain`의 은신 수색·공격, `GameSession`, 학교·회랑 체크포인트.

### 3. 실제 시야로 발각되면 즉시 추격

- 몬스터의 실제 시야·거리·가림 조건으로 플레이어를 발견하면 곧바로 추격 상태로 전환한다. 발견한 뒤 멈추거나 소리 조사처럼 머뭇거리는 지연을 제거한다.
- **완료 기준:** 시각 발견이 확정된 AI 갱신에서 추격이 시작된다. 벽·닫힌 문·유효한 가림 뒤의 플레이어는 시각 발각으로 처리하지 않는다.
- **관련 위치:** `StalkerBrain`의 시각 인식·상태 전이·추격 목적지, `PerceivedTension`의 실제 발견 표현.

### 4. 달리기 소리는 발각이 아니라 소리 위치 조사

- 달리는 발소리만 들었을 때는 플레이어를 발각하거나 즉시 추격하지 않고, **그 소리가 난 위치로 가서 조사만** 하게 한다.
- 조사 목적지는 발소리 이벤트 당시 위치다. 플레이어를 보지 못한 상태에서 현재 위치를 계속 알아내 따라가지 않는다. 조사 중 실제 시야로 발견했을 때만 즉시 추격 규칙을 적용한다.
- **완료 기준:** 가림 뒤 달리기 → 소리 지점 이동·조사 → 시각 발견 시 추격 흐름이 분리된다. 소리 반경·거리 감쇠·문과 벽의 차음은 유지한다.
- **관련 위치:** `PlayerFeedback`, 발소리 소음 이벤트, `StalkerBrain`의 청각 조사·시각 추격 분리.

### 5. 적·오브젝트의 전문적인 모델링과 공포 배치

- 적 모델과 공간 오브젝트의 형태·재질·UV·디테일·애니메이션을 전문적인 수준으로 개선한다. 단순한 장식 추가에 그치지 않고 실루엣·접지·스케일·움직임까지 검수한다.
- 공포감을 만드는 가림·좁은 시야·모퉁이·실루엣·발견 순간을 고려해 적과 오브젝트를 적절히 배치한다. 반복되는 동일 방과 학교 중심 소품 구성을 줄인다.
- **완료 기준:** 실제 플레이 시점에서 적과 소품의 품질·위협이 읽히고, 배치가 이동·문·은신·AI 길찾기를 방해하지 않는다. 원본 자산은 보존하고 개선본은 별도 버전으로 관리한다.
- **관련 위치:** 캐릭터·소품의 `SourceArt`와 `Assets/Art`, `HauntedCorridorPresentation`, `CorridorRun`의 배치.

### 6. 바닥·천장 텍스처를 더 무섭고 사실적으로 개선

- 바닥과 천장의 노후화·습기·얼룩·균열·목재 결·재질의 깊이를 개선한다. 과장된 무늬나 단순한 색 변경보다 실제 낡은 공간처럼 보이게 한다.
- 반복 무늬·UV 늘어짐·이음새를 줄이고, 손전등과 약한 등불 아래에서도 재질이 설득력 있게 보이도록 노멀·거칠기 등을 검수한다.
- **완료 기준:** 실제 카메라의 가까운 바닥·머리 위 천장·긴 복도에서 반복과 왜곡이 두드러지지 않고, 밝기 변화에도 실제 재질처럼 읽힌다.
- **관련 위치:** 회랑 바닥·천장 리소스와 재질, `CorridorRun.MakeMaterial`, 시각 검수 장면.

### 7. 전반적인 어둠과 손전등 배터리 줍기 시스템

- 전반적인 공간을 더 어둡게 하고, 그림자복도처럼 손전등과 제한된 빛에 의존하는 탐색을 만든다. 화면 전체를 단순히 검게 만들어 길을 읽지 못하게 하지는 않는다.
- 손전등 배터리를 회랑에서 주울 수 있게 한다. 배터리 잔량·점등 중 소모·고갈·습득·보충·표시를 하나의 시스템으로 연결한다.
- 소등 중 소모, 일시정지·저장·복원, 최대 잔량, 이미 습득한 배터리의 중복 생성·습득 규칙을 일관되게 정한다. 보급 위치와 양을 경로·난이도에 맞춰 배치한다.
- **완료 기준:** 실제 입력으로 배터리를 발견·습득해 잔량이 바뀌고, 고갈·소등·재점등·일시정지·이어하기가 일관되게 동작한다. 어둠 속 퇴로와 조작 대상이 필요한 거리에서 읽힌다.
- **관련 위치:** `PlayerMotor` 손전등, `Interactable` 습득, `GameShellView` 표시, `CorridorLayout` 보급, 학교·회랑 저장, 조명·노출 설정.

### 8. 길 중간중간 직접 켜는 촛불

- 그림자복도처럼 이동 경로 중간중간에 촛불을 배치하고, 플레이어가 상호작용으로 직접 켤 수 있게 한다.
- 촛대·불꽃·점화 소리·주변의 작은 빛을 실제 위치와 연결한다. 켜진 촛불은 지나간 길을 기억하고 다음 방향을 고르는 표식으로 활용한다.
- 점화 상태를 중단 저장·이어하기에 보존하고, 이미 켠 촛불에서 점화 소리나 효과가 반복되지 않게 한다. 촛불을 켰다는 이유로 자동 안전지대가 되는지는 별도 규칙으로 결정한다.
- **완료 기준:** 실제 입력으로 미점화 → 점화 → 주변 조명 변화가 확인되고, 재접근·일시정지·모드 전환·복원에서 상태와 효과가 맞는다. 다수 촛불의 성능과 길찾기도 검수한다.
- **관련 위치:** 촛불·촛대 모델, `Interactable`, `CorridorRun` 배치·상태, 저장 스키마, 점화 음향·로컬 조명.

### 3. 실제 기기 청감과 첫 플레이 검수

- 헤드폰과 일반 스피커에서 캐비닛 전환에 문 이외 효과가 섞이지 않는지 듣는다. 열림·닫힘의 길이·게인과 빠른 재조작을 확인한다.
- 몬스터 발소리의 좌우·거리·문 너머 감쇠가 실제 위치와 맞는지, 플레이어 발소리·호흡·환경음에 묻히지 않는지 확인한다.
- 처음 플레이하는 사람이 조작·다섯 기억·입구 복귀·은신 위험·유한 폭죽을 이해하는지 관찰한다.
- **완료 기준:** 청감·진행 혼란·불공정한 사망 사례를 위치와 재현 조건으로 기록하고 수정한다. 자동 테스트 통과를 공포감·청감 인증으로 표현하지 않는다.

### 4. 프레임 성능과 안정성

- RTX 2060 SUPER 환경에서 실제 해상도·그래픽 설정·동시 실행 부하를 기록하고 프레임 평균·95백분위·최악 지연을 측정한다. 다른 기기에서도 최소·권장 설정을 정한다.
- 현재 seed 73 장식은 셀별 시각 배치 453개, 등불 25개다. 가까운 그림자 두 개 제한이 실제 GPU 비용을 줄이는지 프로파일러로 확인한다.
- 필요하면 셀/재질 배칭, 그림자 거리·해상도, 먼 장식 표시를 조정한다. 보이는 벽과 실제 AI 시야를 다르게 만들지 않는다.
- **완료 기준:** 목표 기기의 60fps 예산에 맞는 설정과 병목 근거, 긴 탐색·재시작·모드 전환에서 메모리 증가 여부를 기록한다. 숨김 창 감사 결과만으로 최종 사용자 성능을 확정하지 않는다.
