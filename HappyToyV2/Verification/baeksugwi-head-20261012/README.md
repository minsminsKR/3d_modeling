# Baeksugwi head-only motion — 2026-10-12

The existing Baeksugwi actor layers Head_Writhe after its original Run_InPlace
pose only while the encounter state is Chase. The independent scaled-time
head clock continues during stationary Chase, freezes with gameplay pause,
and resets after returning to calm. Existing navigation and eighteen-arm
locomotion keep their current owners and original curves.

The actual red-corridor title clone samples the same Head rotation action on
unscaled time. Its body and twelve planted support limbs remain fixed; face
lighting and eye glow use the current head matrix. Hidden title scenes stop
advancing, and Reduced Motion freezes the title head in a neutral pose.

Sources are in SourceArt/BaeksugwiStudio: the existing packed editable Blender
scene now includes Head_Writhe, generated by author_head_motion.py using
head-motion-profile.json. head-motion-report.json proves unchanged Run action
curve hashes. The original geometry, skin weights, original webapp GLB/PBR,
base Unity FBX and Run_InPlace.anim are retained. The new armature-only FBX
and its Unity importer select four Head rotation channels exclusively.

## Reproduce

Use Blender 4.0.2, Unity 6000.6.0f1 and the source setup documented in
SourceArt/BaeksugwiStudio/README.md. From repository root:

```powershell
blender --background --factory-startup --python-exit-code 1 --python HappyToyV2/SourceArt/BaeksugwiStudio/author_head_motion.py
unity run HappyToyV2 --editor-version 6000.6.0f1 -- -executeMethod HappyToy.V2.Editor.BaeksugwiHeadImport.Apply
Push-Location HappyToyV2
unity test . --editor-version 6000.6.0f1 --mode PlayMode --filter 'BaeksugwiHead;BaeksugwiTitleHead;StudioWraith;StudioImportedRun;StudioRunMoves;StudioCorridorClone' --output Verification/baeksugwi-head-20261012/playmode-verified.xml
unity build . --editor-version 6000.6.0f1 --target StandaloneWindows64 --execute-method HappyToy.V2.Editor.QualityValidation.BuildWindows --args '-v2-build-output Builds/Local-BaeksugwiHead-20261012'
Pop-Location
```

The opt-in native command is `HappyToyV2.exe -quiet-diagnostics
-v2-baeksugwi-head-output <absolute-output-directory>`. It retains the actual
Title instead of audit auto-start, then releases the real seed-73 corridor
mask via three memories and restores a controlled stopped Chase fixture.
Diagnostic audio stays silent and uses an isolated profile; its original
process mute and user preferences are restored on exit. Raw screenshots and
isolated saves are optional reproduction outputs, excluded from source commits.

Use Pillow 10.2.0 and `python HappyToyV2/Tools/quality/preview_baeksugwi_head.py
<output-directory>` to produce the title/chase GIFs and contact sheet from the
recorded actual frame times. Capture interpolation and loop timing differ from
the continuous source action; the clip itself has a tested seamless loop.
