# 회랑의 붉은 교실 제단 검증 — 2026-10-08

새 회랑은 시작점에서 떨어진 경계 출구를 통해 12 × 10 × 3.4m 교실에 연결된다.
기억 다섯 개를 회수한 뒤 실제 제단에 다가가 E로 바치면 폐교의 기억으로 이어진다.
이전 버전 1/2 중단 기록은 기존 지도와 입구 완료 방식을 유지한다.

실제로 통과한 선택 검증은 EditMode 12개, 최종 제단 PlayMode 5개,
회랑 회귀 PlayMode 5개다. 최종 제단 검증에는 실제 봉헌 입력, 0~4개 거부,
거리·일시정지 조건, 경로/충돌, 저장 복원, 성공/실패 챕터 전환과
별도 학교 저장 보호가 포함된다. 전체 프로젝트 테스트 실행을 뜻하지 않는다.

일반 Windows Player의 실제 카메라와 UI를 사용해 입구, 교실 손전등 켜짐/꺼짐,
학교 소품, 칠판 근접, 제단 에임의 6개 화면을 확인했다. 아래 세 화면만 대표
기록으로 보관한다. 액터를 격리한 화면 검증이며 일반 생존 플레이나 FPS 검증은 아니다.

명목 에임 지름은 평소 5px, 상호작용 시 7px이다. 1280×720 네이티브 패널의
픽셀 반올림 결과는 지름 7.5px/반지름 3.75px으로 실제 원형과 흰색이 확인됐다.
개발 빌드 플래그는 꺼졌으며 실행 중 관측 시 TCP/UDP 바인딩은 각각 0개였다.
방화벽 설정을 변경하거나 모든 시점의 네트워크 상태를 보장한 것은 아니다.

결과·범위·수정한 발견 사항은 [verification.json](verification.json), 편집 가능한
모델 4개의 Blender/FBX/UV/상대 경로 검증은
[authored-source-proof.json](authored-source-proof.json)에 기록했다. 필수 제작 소스와
고정 버전 재생성 안내는 `SourceArt/CorridorAltarChamber`와 `SOURCE_HANDOFF.md`에 있다.
