# 폐교 몬스터 계단 이동 검증 — 2026-10-08

폐교의 몬스터는 실제 연결된 계단을 따라 층을 옮긴다. 학교 모드에만 이동 정책을
적용하며, 처음 등장하는 조건·시야·소리·숨기·문·마네킹의 시선/손전등 규칙은 유지한다.
계단을 포함하는 처음 수색 접근과 근처의 작은 범위 수색을 구분한다. 저장 버전은 1이다.

선택 PlayMode 검증 10개가 통과했다. 새 2개는 실제 가면/베이비 등장 절차 뒤의
계단 왕복, 계단 중간 일시정지, 다른 층에서의 전체 학교 저장/새 씬 재개,
베이비의 기록된 증거를 향한 계단 수색을 확인한다. 마지막 수색 단계만 테스트에서
생산 코드 BeginSearch를 직접 호출하며, 대상 위치·타이머·속도를 임의로 바꾸지 않는다.
공간 이동 중 몬스터 워프와 속도 변경도 없다. 다른 위협과 플레이어는 통제한 검증이다.

일반 Windows Player에서도 가면의 2층→1층→2층, 베이비의 지하→1층→지하
네 경로를 실제 NavMeshAgent로 완료했다. 중간 높이를 지속 관측하고 물리적 바닥
지지를 확인했다. 시작에 준비된 액터 스냅샷을 사용하며 첫 등장/일반 생존을 인증하지 않는다.
각 경로의 전체 실제 위치 시계열은 [native-stairs.json](native-stairs.json)에 있다.

- [베이비가 올라오는 계단](baby-basement-ascent.png)

검증 소스는 `Assets/Tests/PlayMode/CloudSchoolStairPursuitTests.cs`, 네이티브 이동 기록은
`Assets/Scripts/SchoolStairAudit.cs`이다. 기존 학교 씬·계단·내비게이션 자산을 바꾸지 않았다.
결과와 검증 범위는 [verification.json](verification.json)에 있다. 전체 테스트나 FPS
검증을 뜻하지 않는다. 원본 코드·메타·제작 소스는 `SOURCE_HANDOFF.md`의 전달 검사를 따른다.
