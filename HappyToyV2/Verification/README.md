# 검증 산출물 보관 정책

과거 테스트 플레이의 로그, 화면·음향 캡처, 결과 보고서와 중복 테스트
빌드는 재생성 가능한 산출물이다. 정리할 때 검증 도구, 테스트 코드와
모델·텍스처·편집 원본은 유지한다.

새 검증 산출물은 이 폴더 또는 `Builds/`에 생성할 수 있지만 새 파일은 Git에서
제외한다. 기존에 추적된 산출물은 정리가 완료될 때까지 추적 상태로 남는다.
한 번 사용한 기록을 소스에 계속 누적하지 않는다. 모델·이미지 생성에 사용한
실제 입력과 제작 이력은 `SourceArt/`에 보관한다.

`native-readiness/runtime-shader-anchors.json`은
`Tools/quality/verify_build_inputs.py`가 사용하는 빌드 검증 기준이므로 유지한다.
플레이어의 `quality-build.json`, 입력 검증 기록, 실행 파일, `_Data`, DLL과
크레딧은 유지할 최신 빌드 폴더 안에 함께 둔다.
