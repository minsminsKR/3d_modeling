# 출시 준비 체크리스트

갱신: 2026-10-03. 현재 상태는 **개발 중 / 출시 불가**. 체크를 통과하려면 해당 소스의 새 실행 결과가 필요하다. 과거 빌드나 외부 컴파일 성공은 Unity 실행 검수를 대체하지 않는다.

## 소스에서 구현한 플레이 골격

- 7개 필수 기록 → 복원 → 현관 탈출, 사망 → 재시작 흐름
- 일시정지·기록·설정·결과 화면, 한국어 폰트와 접근성 옵션
- 층별 추격, 예고·회복·공격 방향, 목격된 은신과 폭죽 유인
- 실제 발 접촉에 따른 소음 조사, 낮은 자세/손전등 상태에 따른 발견 지연
- 물·혈흔 재질, 지하 음향·발걸음 물결

이는 기능 구현 목록이다. 전체 생존 플레이나 상품 품질의 승인 목록이 아니다.

## 검증 범위 원칙

- 자동 소스 검사, 순수 C# 상태 검사, 실제 Unity API 참조 외부 컴파일을 각각 기록한다
- 새 `stealth` 검사는 실행 전까지 NOT RUN이며, 통과해도 통제된 입력/물리 검사이지 적 난이도나 생존 완주 증거가 아니다
- authored SchoolAnnex 씬, 메타, 빌드 선택은 보존한다. 검사 통과를 위해 보존 해시를 바꾸거나 Generate/Expand를 실행하지 않는다
- 초안 PR에서 계속 개발한다. main 병합·상용 배포·구매·계정/라이선스 동의는 이 체크리스트로 승인되지 않는다
