# 출시 준비 체크리스트

갱신: 2026-10-04. 현재 상태는 **개발 중 / 출시 불가**. 체크를 통과하려면 해당 소스의 새 실행 결과가 필요하다. 과거 빌드나 외부 컴파일 성공은 Unity 실행 검수를 대체하지 않는다.

## 이번 추격 개선: 구현 완료, 엔진 재검사 대기

마지막 확인 위치를 기준으로만 가까운 길을 조사하고 고개를 돌리는 제한 시간 수색을 구현했다. 갈 수 없는 지점에서 수색이 무한히 지속되지 않으며, 다른 층으로 간 플레이어 때문에 같은 층의 폭죽 조사를 멈추던 등불 가면도 수정했다. 캐비닛 진입 목격/시야 밖 은신·반복 진입 악용·유한 폭죽·수색 종료 등 통제된 Unity 사례 5개를 추가했다. 전체 검사는 이제 21개다.

이는 아직 새 엔진 실행을 통과한 결과가 아니다. 오디오 실패 조건은 유지하고, 실제 listener callback과 DSP/소스 진행을 관찰하는 별도 진단만 추가했다. 비어 있는 데이터를 무음 WAV로 만들거나 진단 값을 기존 오디오 합격으로 사용하지 않는다. 실제 확인된 최신 결과는 아래 #6의 15/16이며, 새 구현의 생존 난이도·감각 품질·최신 Windows 내보내기는 미검증이다.

## 확인된 클라우드 진전

UBA #4는 `58f5cf9`에서 **EditMode 6/6·PlayMode 6/6 검사와 Windows 빌드를 모두 통과**했다(실패·건너뜀·판정 불가 0). 씬 보존, 실제 키보드 입력·낮은 자세·발소리·적 청각/인식·가림, 공격 예고·회피, 필수 조사물 경로, 일시정지·재시작, 기록·탈출의 통제된 사례가 실제 엔진에서 확인됐다. Windows 테스트 ZIP 73,163,952바이트의 186개 항목 CRC도 통과했다. `CLOUD_QA.md`와 `Verification/cloud-tests/build-4-results.json`에 정확한 범위를 기록한다. 이후 결과 문서 갱신은 검사된 소스를 변경하지 않는다. 전체 일반 입력 생존 완주나 수동 감각/성능 검수의 통과는 아니다.

### #6 최신 결과: 15/16 통과, 음향 캡처 미해결

실제 엔진 검사 소스는 `e3122fb`다. EditMode6/6·PlayMode9/10 통과, 실패1·건너뜀0이며 엄격한 게이트가 새 플레이어 내보내기를 막았다. 동일한 일반 입력 7기록 전략이 79.70초·237.63m에 다시 완주했다. 한국어 큰 글씨/고대비의 지정 화면·비율 검사와 표지판 렌더 검사가 통과했으며, 실제 PNG9장을 해시 확인 후 모두 검토했다. 반전/중복된 방 표지판은 사라졌고 지정 화면에 뚜렷한 잘림은 보이지 않는다.

음향은 고정 캡처 시계를 사용해도0/96,000샘플이다. 실제 게임 믹스·일시정지 무음·기기 청취는 확인되지 않았다. 같은 nosound 작업자를 반복 실행하거나 빈 데이터를 통과시키지 않는다. 마지막 성공한 Windows 실행 파일은 #4이며 #6에는 새 실행 파일이 없다. 이후 일시정지 카드의 “기록0/4”를 “주요 단계0/4”로 고친 짧은 문구 수정은 소스 검사만 거친다. 엔진/이미지 증거를 새 소스에 소급하지 않는다.

### #5에서 새로 확인한 범위

`db36acf`의 UBA #5는 **16개 중 14개 통과, 2개 실패, 건너뜀 0**으로 빌드가 중단됐다. 일반 키보드/마우스 입력을 쓰는 7기록 생존 경로가 79.38초·237.54m에 완주했고, 위층/지하 계단 왕복·실제 은신·유한 폭죽·네 추적자 최대 활성 상태를 확인했다. 길과 타이밍을 미리 아는 한 가지 자동 전략이며, 초행자의 난이도나 모든 선택 조우를 승인한 결과는 아니다.

실제 카메라와 한국어 타이틀 PNG를 회수·검토했다. 방 표지판의 반전/중복 노출과 제목/버튼의 부족한 글줄 높이를 발견했다. 음향은 믹서에서 샘플을 0개 받아 판정할 수 없었으며, 무음 게임이라는 뜻이 아니다. 관련 수정과 고정 캡처 시계 실험은 다음 실제 실행 결과가 필요하다. 소프트웨어 렌더러 수치를 대상 PC의 FPS로 해석하지 않는다. 자세한 결과는 `Verification/cloud-tests/build-5-results.json`과 `build-5-experience.json`에 있다.

## 소스에서 구현한 플레이 골격

- 7개 필수 기록 → 복원 → 현관 탈출, 사망 → 재시작 흐름
- 일시정지·기록·설정·결과 화면, 한국어 폰트와 접근성 옵션
- 층별 추격, 예고·회복·공격 방향, 목격된 은신과 폭죽 유인
- 실제 발 접촉에 따른 소음 조사, 낮은 자세/손전등 상태에 따른 발견 지연
- 물·혈흔 재질, 지하 음향·발걸음 물결
- 중복 재시작 차단, 시작 화면 목적지 보존, 로딩 실패 시 요청 해제와 이벤트 중단 정리

이는 기능 구현 목록이다. 전체 생존 플레이나 상품 품질의 승인 목록이 아니다.
