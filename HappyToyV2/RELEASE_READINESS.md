갱신: 2026-10-04. 현재 상태는 **개발 중 / 출시 불가**. 체크를 통과하려면 해당 소스의 새 실행 결과가 필요하다. 과거 빌드나 외부 컴파일 성공은 Unity 실행 검수를 대체하지 않는다.

## #8 최신 결과: 실제21검사와Windows빌드 통과

정확한 검사/내보내기 소스는 `9230608`이다. **EditMode6/6·PlayMode15/15, 실패·건너뜀·판정불가0**을 두 원본 XML에서 확인했고 최종 빌드도SUCCESS다. #7에서 미확인이던 EditMode6개와 기존 엄격한 AudioRenderer검사가 이번 실행에서 모두 통과했다.

새5개 추격/시야 차단/수색/캐비닛/폭죽/등불 사례와 일반 입력7기록 생존 경로(79.407초·237.542m)가 통과했다. 공식 Recorder와 같은 빈 Render진행 호출을 사용하자 실제 양의 버퍼에서96,000샘플을 얻었고 비무음·클리핑0을 확인했다. 일시정지의24,000샘플은 실제0이었다. 빈 버퍼를 샘플로 계산하거나 조건을 완화하지 않았다. 주변음+손전등 입력의 짧은 오프라인 믹스 검사이며 개별 위협음·발소리/폭죽·거리 감쇠·기기 청취 검수는 별도다.

최신 원본WindowsZIP73,166,499바이트/186파일을 보존했다. 별도 정리본67,573,893바이트/185파일은 Burst백업 텍스트1개만 제외하고 나머지 내용을 그대로 유지하며 두 번 생성한 결과가 동일하다. 개발용 표기/계측·실제 새PC 실행·자산 상용 권리의 한계는 남아 있어 출시 승인본은 아니다. 문서만 정리하는 후속 커밋에는 이 엔진 증거를 새 실행처럼 소급하지 않는다.

## 이전 #7 결과: 추격 개선 통과, 오디오 실패·EditMode 미확인

실제 엔진 소스는 `b4a454e`다. **PlayMode14/15 통과·오디오1실패·건너뜀0**이다. EditMode프로세스가 첫 assembly reload중9.667초만에 종료됐고 XML/완료문구가 없어 **6개는 이번 실행 미확인**이다.20/21로 집계하지 않는다. 전체 빌드는 실패했으며 새 플레이어가 없다.

마지막 확인 위치 주변 수색·시야 차단/재발견·막힌 경로의 제한 시간 종료·목격된/보이지 않은 캐비닛 진입·반복 진입 공격 회피 악용·Q폭죽 물리와 유한 수량/수명·등불 자기 층 소리 조사 등 새5개 사례가 모두 통과했다. 별도의 일반 입력7기록 전략도80.13초·237.73m로 완주했다. 새 사례는 통제된 배치/격리 검사이고, 생존 경로는 기존 모든 조우와 속도를 유지한 동일한 사전 계획 전략이다.

처음으로 실제 게임 listener의48kHz스테레오1초 PCM(96,000샘플)을 회수·해시 검증했다. 비정상/클리핑0, 일반 믹서 DSP진행을 확인했다. 이후 AudioRenderer녹음 모드에서는 DSP와 샘플 수가 멈췄으므로 기존 오디오 게이트는 계속 실패다. 실제 믹스 일부를 얻은 것과 손전등/발소리/폭죽/거리 감쇠·일시정지·기기 청취 검수는 구분한다. 다음 공식 Recorder방식 빈 Render호출 실험도 기존 합격 조건을 유지하며 아직 실행 전이다.

### #6 최신 결과: 15/16 통과, 음향 캡처 미해결

실제 엔진 검사 소스는 `e3122fb`다. EditMode6/6·PlayMode9/10 통과, 실패1·건너뜀0이며 엄격한 게이트가 새 플레이어 내보내기를 막았다. 동일한 일반 입력 7기록 전략이 79.70초·237.63m에 다시 완주했다. 한국어 큰 글씨/고대비의 지정 화면·비율 검사와 표지판 렌더 검사가 통과했으며, 실제 PNG9장을 해시 확인 후 모두 검토했다. 반전/중복된 방 표지판은 사라졌고 지정 화면에 뚜렷한 잘림은 보이지 않는다.

음향은 고정 캡처 시계를 사용해도0/96,000샘플이다. 실제 게임 믹스·일시정지 무음·기기 청취는 확인되지 않았다. 같은 nosound 작업자를 반복 실행하거나 빈 데이터를 통과시키지 않는다. 마지막 성공한 Windows 실행 파일은 #4이며 #6에는 새 실행 파일이 없다. 이후 일시정지 카드의 “기록0/4”를 “주요 단계0/4”로 고친 짧은 문구 수정은 소스 검사만 거친다. 엔진/이미지 증거를 새 소스에 소급하지 않는다.

### #5에서 새로 확인한 범위

`db36acf`의 UBA #5는 **16개 중 14개 통과, 2개 실패, 건너뜀 0**으로 빌드가 중단됐다. 일반 키보드/마우스 입력을 쓰는 7기록 생존 경로가 79.38초·237.54m에 완주했고, 위층/지하 계단 왕복·실제 은신·유한 폭죽·네 추적자 최대 활성 상태를 확인했다. 길과 타이밍을 미리 아는 한 가지 자동 전략이며, 초행자의 난이도나 모든 선택 조우를 승인한 결과는 아니다.
