# 물·재질·공간 피드백 개선 — 2026-10-02

이 단계는 저장된 다층 씬을 그대로 사용하면서 화면의 재질 반응과 이동 피드백을 개선한다. 기존 스크린샷과 소스를 확인해, 조명에 반응하지 않던 물/혈흔 재질 및 Windows 글꼴에 의존하던 한국어 표지판을 대상으로 삼았다.

## 구현

- **침수 공간의 물:** 기존 단순한 사인무늬 대신 서로 다른 방향·크기의 표면 노멀, 실제 방 조명과 손전등에 반응하는 젖은 반사광, 거리 안개를 적용
- **발걸음 물결:** 실제 발소리 접촉 위치에서 최대 4개의 물결을 유지하고 2.4초 내 소멸. 지하 계단을 물로 취급하지 않으며, 물 경계에서는 소리와 물결이 같은 발 위치를 사용
- **쾌적성:** 메뉴/일시정지 중 물결·표면 시간과 안개·환경음 혼합이 멈춤. 움직임 완화 옵션은 파동 노멀을 즉시 평탄화하고 기존 접촉 물결도 제거
- **혈흔 재질:** 고정된 응고 무늬, 가장자리 건조감, 거칠기 변화와 젖은 부분의 조명 반응. 새 메시/탄젠트나 움직이는 혈흔 효과는 추가하지 않음
- **층별 음향:** 지하 물방울 간격을 불규칙하게 하고 루프 끝을 감쇠. 바닥/벽 너머에서는 낮은 음량·저역 통과 필터를 적용하고, 가까운 같은 층 추격 상황에만 환경음을 낮춤
- **한국어 표지판:** 9개 관리 대상 TextMesh가 동봉한 한국어 폰트를 사용. 공유 폰트 재질과 아틀라스 갱신을 안전하게 처리하며, 문구·크기·위치와 씬 파일은 유지

두 셰이더는 기존 이름·GUID·투명 렌더 큐를 유지하고 각각 한 패스만 사용한다. 카메라 depth/opaque 텍스처, SSR, 추가 카메라, 새 렌더 패스는 요구하지 않는다. 기본 물 알파는 0.29–0.59로 설정했지만, 이 수치는 실제 화면의 가시성 검수를 대신하지 않는다. 기존 추가 조명 4개 제한과 추가 조명의 그림자 비활성 설정은 그대로다.

## 실제로 실행한 검증

| 검증 | 결과 | 범위 |
| --- | --- | --- |
| Python 검증기 단위 테스트 | 24개 통과 | 검사 도구의 실패 탐지 |
| C# 공격/물결 상태 테스트 | 29 + 20개 통과 | 실제 순수 C# 헬퍼 실행, Unity 런타임 아님 |
| 정적 검사 | C# 82개·GUID 847개 통과 | 문법, 참조 이름, 메타·LFS·보존 해시 |
| 실제 Unity API 참조 C# 컴파일 | 4개 구성, 오류 0 | Editor 런타임 59개, Editor 소스 23개, Linux/Windows 플레이어 런타임 각 59개 |
| 오프라인 HLSL 컴파일 | DXIL 96개 + Vulkan SPIR-V 8개 통과 | 정식 Editor에 포함된 URP/Core 17.6 헤더, 컴파일 진단 없음 |
| 한국어 표지판 글리프 | 9개 표지판·44개 고유 표시 문자 누락 없음 | 폰트 파일의 cmap 검사 |
| 저장 씬 보존 | 원본 SHA-256 동일 | 씬·메타·빌드 선택 보존 |

실제 Unity API 참조 컴파일은 공식 Unity 6000.6.0f1 및 버전이 맞는 URP/Input System/AI Navigation 어셈블리를 사용했다. 플레이어 구성에서는 UnityEditor 참조를 제외했다. 외부 컴파일러 단계에는 기존 obsolete API, 직렬화 필드, netstandard 참조 호환성 경고가 남아 있다. 따라서 이 단계를 “경고 없는 Unity 빌드”라고 부르지 않는다.

셰이더 검사는 Forward/Forward+, 정점 조명, 메인 그림자 모드, 추가 그림자, 쿠키, 안개, 인스턴싱과 소프트 그림자 품질을 포함한다. DXC의 SM6/SPIR-V 컴파일을 Unity ShaderLab 임포트·스트리핑·특정 GPU 렌더 성공으로 확대 해석하지 않는다.

증거는 `Verification/quality-surface/`에 있다. C# 및 셰이더 보고서에 검사 대상의 SHA-256을 기록했고, 코드 변경 후 일치 여부를 다시 확인했다. 재현 도구는 `Tools/quality/compile_unity_api.py`와 `compile_surface_shaders.py`; 명령과 입력 요구 사항은 `Tools/quality/README.md`에 있다. CI는 가벼운 정적 검사와 49개 순수 C# 검사를 반복하며, Editor/셰이더 외부 컴파일은 준비된 클라우드 도구로 별도 수행했다.

## 여전히 필요한 Unity 검수

1. 실제 프로젝트 임포트, 새 폰트·재질 임포트와 ShaderLab 변환/스트리핑
2. 손전등·방 조명 아래 물/혈흔의 밝기, 바닥·단서 가시성, 과한 반사광과 투명 정렬
3. 걷기·달리기·경계 진입·은신·일시정지·편의 옵션 전환의 실제 물결과 소리 동기화
4. 새 폰트의 표지판 글자 폭·줄바꿈·가림 및 동적 아틀라스
5. 실제 음향 청취, GPU 비용, 플레이어 빌드, 지하 귀환을 포함한 전체 완주

이번 단계에서는 새로운 게임 렌더를 만들지 못했다. 기존 `Assets/Verification/annex/` 이미지가 이번 수정의 결과라는 뜻은 아니다. 씬 재생성, 방 구조/충돌/추격 동선 변경, 몬스터 정체성 교체는 하지 않았다.
